FLAGSHIP SYSTEM

Agent × Obsidian
个人知识操作系统

把来源、知识和当前有效结论组织成一条可追溯、可审批、可持续迭代的工作流，让 AI 协作不再依赖一次性对话记忆。

持续使用产品架构Human Gate
PROBLEM / 01

要解决的问题

信息混写

来源、摘要与结论混在一起

事实和判断缺少清晰层级，后续复用时难以确认依据。

协作漂移

上下文衰减与跨 Agent 状态漂移

更换客户端或进入新会话后，进度、规则和权威版本容易失真。

生效失控

结论过早固化

AI 生成的候选判断不能在没有人工确认时直接成为当前有效结论。

MECHANISM / 02

系统机制

  1. 01Raw / Capture原始信息进入
  2. 02Source来源留痕
  3. 03Knowledge事实分层与复用
  4. 04Current Truth当前有效结论
Human Gate

候选结论必须经过人工审批，不能由 AI 自动生效。

ROLE / 03

我的角色

问题定义

识别真正需要被系统化的协作摩擦

从上下文衰减、权威版本漂移和敏感边界出发，定义系统必须解决的问题。

产品架构

设计信息层级、状态流和入口

确定 Source、Knowledge、Current Truth、MOC 与交接之间的职责关系。

规则设计

建立权限、审批和唯一权威版本

让 AI 的可执行范围、人工边界和变更记录有明确约束。

验收迭代

用真实任务持续验证

AI 协助实现和迭代，我负责判断是否符合任务目标与安全边界。

USE CASE / 04

真实用例｜知识蒸馏系统

问题

多来源内容难以稳定沉淀

长文章、截图和多来源信息容易让摘要、事实与结论混写。

工作流

来源留痕到候选结论

Raw／Source → 结构化蒸馏 → Knowledge → Current Truth 候选。

真实用途

公开内容持续进入知识库

用于公开文章的来源留痕、结构化精读、知识卡片与行动建议沉淀。

APPLICATION / 05

对下一份工作的应用

业务研究与复盘

让分散信息成为可复用的决策依据

可用于沉淀竞品研究、用户反馈、实验复盘等业务资料，让关键判断能够回溯来源并持续更新。

跨角色协作

围绕同一来源和当前结论协作

可帮助运营、产品、数据和研发共享任务背景、依据与状态，降低跨角色交接中的信息丢失和版本混乱。

部门能力沉淀

把个人经验转成团队可复用机制

把高频工作固化为可复用模板、Skill 与人工审批流程，使方法能够被复用、校验和持续迭代。

VALIDATION / 06

验证与边界

真实验证

V1 已部署并持续迭代

系统已用于公开文章知识蒸馏、求职证据管理及跨 AI 客户端协作。

能力证明

从模糊问题到可运行机制

证明我能定义问题、组织复杂信息、建立人工门禁并持续验收。

公开边界：本案例不展示私人知识内容、受限来源原文、物理路径、凭据或未公开求职材料。
